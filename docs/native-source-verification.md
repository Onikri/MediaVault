# Живые проверки прямых адаптеров

## Oracle, 15 ноября 2026 года

Код ветки выполнялся в отдельном процессе на VM. Запущенные сервисы не пересобирались и не перезапускались. Журнал содержит метаданные и длительности. Страницы загружались для проверки формата и CBZ во временную папку.

### Manga-shi 1.6.53

- «Синяя тюрьма», запрос `Blue Lock`, три последовательные пары замеров на одном source ID. Прямой поиск **0,269–0,720 с**, Suwayomi **2,988–3,964 с**. В каждой паре совпал найденный тайтл.
- На первых двух страницах прямого каталога по 20 разных карточек. Разобраны 291 фильтр, жанры, теги и описание карточки.
- Оба маршрута вернули 374 главы. Список глав занял **18,897 с** напрямую и **18,920 с** через Suwayomi. Старая ссылка сопоставилась с тем же тайтлом и главой.
- На проверенной главе совпала 71 страница. Прямой разбор главы занял **0,153 с**, сборка CBZ заняла **1,159 с**. Все 71 файла найдены в ZIP, проверка CRC прошла.

### MangaHub, 11 установленных вариантов

На десяти вариантах запрос `Naruto` нашёл тот же тайтл, что Suwayomi. В третьем парном прогоне поиск занял **0,22–0,58 с** напрямую и **1,04–4,04 с** через Suwayomi. На каждом из десяти разобраны две страницы по 30 карточек, справочник из 147 меток, результаты фильтра Action, карточка и список из 748 глав.

Старые ссылки вида `/suwayomi/…` при первом успешном открытии сохраняют соответствие ID в SQLite MediaVault. Повторное открытие тайтла, главы и URL страницы использует эту запись при недоступном Suwayomi. Отключение проверено локально на контрактном тесте. Массовая миграция старых ссылок и проверка отключения Suwayomi на Oracle остаются в плане.

### Madara

В отдельном процессе на Oracle по одному разу сравнили запросы к одному и тому же тайтлу. Для каждой строки совпали название, число глав, сопоставление старой ссылки на главу и число страниц. Проверили общий маршрут каталога MediaVault, карточку и словарь жанров. На Oracle и на устройстве собрали CBZ для всех восьми профилей и проверили CRC. Скачивание TritiniaScans на Oracle прошло при повторном запуске с тайм-аутом чтения 18 секунд вместо 9.

| Источник | Глав | Страниц | Прямой поиск, с | Suwayomi, с |
| --- | ---: | ---: | ---: | ---: |
| Bun Manga | 579 | 1 | 1,35 | 1,46 |
| GakaMangas | 30 | 10 | 1,06 | 2,17 |
| LHTranslation | 139 | 17 | 0,27 | 0,94 |

- На Lovesjane Scans WordPress отдаёт абсолютные HTTP-ссылки на собственные файлы в `/wp-content/uploads/`. После нормализации в HTTPS главы 36 и 37 «Miyeon» дали по четыре страницы и два валидных CBZ.
- Счётчики WordPress из элементов `.count` теперь исключаются из названия жанра. Старые задания с ярлыками вроде `drama (2)` получают новый идентификатор фильтра с сохранением страницы очереди. Фильтр `drama` возвращает «Miyeon».
- Manga Eclipse отдал тайтл под названием `Top 3 Great Heaven Sovereign` на устройстве и `Great Heaven Sovereign` на VM. На Oracle оба маршрута вернули одинаковый тайтл по доступному там имени.
- У каталога Borat Scans и ManhuaUS на устройстве отказ доступа. Sleepy Translations ответил HTTP 429. Эти профили остаются на прежнем маршруте в приложении. Для остальных неактивных профилей пока есть сверка конфигурации с исходниками, а живые прогоны впереди.

### Madara, вторая серия проверок

На Oracle прогнали 49 отложенных профилей. У 26 прямой поиск вернул контрольный тайтл из каталога самого источника, у 29 удалось разобрать карточку. Для отдельных операций результаты внесены в CSV. Код ещё для 19 профилей сохраняет отличия установленных расширений, включая форму Aqua Manga, публичный маршрут поиска Manhwa-raw, альтернативный шаблон Gourmet Scans и интервалы запросов для Cocomic и Top Manhua.

На пяти новых профилях повторили тот же тайтл через Suwayomi и чистый адаптер. Списки глав совпали. У каждой проверенной главы CRC архива прошёл на Oracle.

| Источник | Глав | Страниц в CBZ | Прямой поиск, с | Suwayomi, с |
| --- | ---: | ---: | ---: | ---: |
| Grabber Zone | 91 | 24 | 0,59 | 2,63 |
| Aqua Manga | 338 | 26 | 0,13 | 1,23 |
| Manhua Plus | 3 364 | 12 | 0,34 | 2,02 |
| ManhwaNex | 19 | 4 | 0,40 | 2,96 |
| MangaRead.org | 200 | 15 | 0,36 | 1,20 |

- Aqua Manga содержит сами ссылки в списке глав. Изменение восстанавливает всё оглавление «Nano Machine» из 338 глав. У «Magic Emperor» на устройстве обнаружено 942 ссылки на главы.
- Manhua Plus отдаёт оглавление целиком в одном HTML-документе. Убрана обрезка после 1 500 глав. Существенно большие постраничные источники, например Top Manhua, требуют отдельной проверки выдачи за пределами первых 100 страниц каталога глав.
- У Cocomic новый шаблон карточки. На устройстве подтверждены описание, 15 жанров и 105 глав. Изображения главы для этого профиля ещё предстоит сверить.
- Borat Scans и ManhuaUS на VM возвращают отказ доступа и на HTML-каталоге. Sleepy Translations возвращает HTTP 429. Comics Valley и Lily Manga вернули HTTP 523 и 521. У Zinmanga одна из страниц контрольной главы вернула HTTP 404 при скачивании. Эти источники сохраняют текущий маршрут Suwayomi.
