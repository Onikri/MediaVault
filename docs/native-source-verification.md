# Живые проверки прямых адаптеров

## Oracle, 15 ноября 2026 года

Код ветки выполнялся в отдельном процессе на VM. Запущенные сервисы не пересобирались и не перезапускались. Журнал содержит метаданные и длительности. Страницы загружались для проверки формата и CBZ во временную папку.

### Manga-shi 1.6.53

- «Синяя тюрьма», запрос `Blue Lock`, три последовательные пары замеров на одном source ID. Прямой поиск **0,269–0,720 с**, Suwayomi **2,988–3,964 с**. В каждой паре совпал найденный тайтл.
- На первых двух страницах прямого каталога по 20 разных карточек. Разобраны 291 фильтр, жанры, теги и описание карточки.
- Оба маршрута вернули 374 главы. Список глав занял **18,897 с** напрямую и **18,920 с** через Suwayomi. Старая ссылка сопоставилась с тем же тайтлом и главой.
- На проверенной главе совпала 71 страница. Прямой разбор главы занял **0,153 с**, сборка CBZ заняла **1,159 с**. Все 71 файла найдены в ZIP, проверка CRC прошла.

### MangaHub, 11 установленных вариантов

На десяти вариантах запрос `Naruto` нашёл тот же тайтл, что Suwayomi. В третьем парном прогоне поиск занял **0,22–0,58 с** напрямую и **1,04–4,04 с** через Suwayomi. На каждом из десяти разобраны две страницы по 30 карточек, справочник из 147 меток, результаты фильтра Action, карточка и список из 748 глав.

Старые ссылки вида `/suwayomi/…` при первом успешном открытии сохраняют соответствие ID в SQLite MediaVault. Повторное открытие тайтла, главы и URL страницы использует эту запись при недоступном Suwayomi. Отключение проверено локально на контрактном тесте. Массовая миграция старых ссылок и проверка отключения Suwayomi на Oracle остаются в плане.
