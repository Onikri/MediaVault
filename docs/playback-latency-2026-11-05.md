# Проверка подготовки потоков — 5 ноября 2026

Реальные запросы с Oracle VM через опубликованный HTTPS API. Замеры не являются
браузерным временем до первого кадра у пользователя: последняя миля и декодирование
в них не входят. Проверялись только первые 1024 байта сегмента, серия не скачивалась.

| Источник | Холодная подготовка | Повторная подготовка | Первый манифест | Первые байты сегмента |
| --- | ---: | ---: | ---: | ---: |
| AniLiberty / AniLibria, опубликованная серия «Моей геройской академии» | 0,919 с | 0,054 с | 45–48 мс | 74–144 мс |
| Alloha, доступная озвучка «Твоего имени» | 6,773 с | 0,052 с | 46–48 мс | 95 мс |
| Kodik, доступная озвучка «Твоего имени» | 0,802 с | 0,100 с | 45–46 мс | 147–163 мс |

Alloha опубликовал 2160/1440/1080/720/480/360p; выбранная версия Kodik — 720/480/360p.
Это реальные лестницы конкретных версий, а не гарантия наличия 4K у любой озвучки.
Три одновременные тёплые подготовки AniLiberty вместе с чтением манифестов/первых
байтов завершились за 0,576 с. Поиск в публичном каталоге AniLiberty занял 0,117 с,
список 13 опубликованных серий — 0,137 с. Перечисление плееров страницы — 1,291 с.

Из холодного времени Alloha 6,023 с занял динамический Chromium-парсер,
0,301 с — манифест. Его нельзя считать общей задержкой Google Drive: Drive-файл
уже открывается через браузерный диапазонный/дешифрующий путь, без такого парсера.
Реальный облачный файл в этом замере не открывался; его декодирование и сохранение
буфера проверены отдельным контролируемым MP4-контрактом.

Изменения: динамические публичные плееры могут использовать два ограниченных
слота на двухъядерной VM; одинаковая подготовка объединяется в один запуск.
Память VM — около 12 ГБ, доступно около 7,7 ГБ при проверке. Переводы/Google cookies
никогда не передаются в этот изолированный Chromium. Проверки публичных адресов,
защиты и запретов приватных сетей сохраняются.

Превью таймлайна теперь начинает HLS сразу около указанного курсором времени.
Повторное открытие уже декодированного кадра не запрашивает видео заново. Кэш
ограничен 120 позициями. Нарезка 1260 кадров для каждой серии в фоне не запускается:
она требует чтения/декодирования большого объёма видео и конкурирует с просмотром.

Реальная проверка WebAssembly: Depth Anything V2 Small (проверенный SHA-256,
27 258 801 байт), подготовка с чтением локального тестового транспорта — 1180 мс,
инференция 196×112 — 220 мс. Транспорт весов в тесте локальный, нейросеть настоящая.
Это не замер загрузки модели через интернет или времени на телефоне.
