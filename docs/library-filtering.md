# Library taxonomy and signed search

`server/catalog-taxonomy.json` is the shared semantic genre/format dictionary for Python and the client. It supplements owner-managed rules; private rules and source facts are not rewritten. Owner category overrides take precedence. Unknown descriptive source categories remain flat tags; numeric IDs never become display labels. Ordinary books retain recognized genres only. Hentai is scoped to anime, manga and novels; an adult rating alone never implies that genre.

Genre and tag includes each use OR; the groups combine with AND. Any exclusion wins. Legacy comma-delimited requests and JSON string arrays are accepted (up to 64 per group); arrays preserve labels containing commas. Search exclusions are independent of the owner's site-wide label visibility settings. Signed conditions run before totals and paging. Work-level matching checks every verified source identity; unknown external identities never merge just because their titles resemble one another. Webtoon presentation is independent of manga origin/type.

For non-manga signed browsing the server's collected index supplies the result pages and totals; it does not imply that every remote provider is fully indexed. Normal metadata discovery continues feeding it. Source requests do not send an OR list as one provider-specific genre. Results retain their positive/negative state when opening a title and returning.

`catalog_taxonomy.maintain_books` resumes in batches (20 title projections or 200 vocabulary entries per transaction, with a pause between batches). It removes the ordinary-book contribution from derived filtering data. It preserves source facts, titles, credentials and all catalogue jobs/cursors. No source crawl is restarted and no extra HTTP request is made by this maintenance. The existing 12-worker crawl scheduler and its per-host pacing remain intact. The persistent raw facet cache introduced by Claude remains usable; classification is applied separately.

The library has one toolbar, relocated into the existing navbar/dock on scroll. A focused input holds its current parent until blur to preserve composition, focus and selection. Existing collection filters retain their original placement. The visible library kind rail owns the scrolled section label. Reduced-motion mode has no animated relocation.

Validation: neutral SQLite and Node contracts cover categories, OR/AND/exclusions, source-group matching, paging, scope, formats, comma-containing labels and restart-safe cleanup. `tests/catalog-morph-browser.cjs` runs in CI with fixture controls at 320, 390, 768 and 1440 pixels, checking one toolbar, section brand, signed choices, focus, reverse scroll and overflow. These are UI contracts, not live source crawling or ML inference.

Source-derived hentai classification uses the explicit provider/hostname list in `sourceGenres.hentai` in the shared JSON. It applies to manga, anime and novels, never to ordinary books or films. A host must match exactly or be its subdomain; a generic adult flag or an arbitrary hostname containing “hentai” is insufficient. Raw source facts are retained. Explicit “Не хентай” / “Non-hentai” wins across every member of the existing work identity, even when the label is hidden from display. Public cards carry a veto flag so client merges and late metadata enrichment cannot reintroduce the genre. SQL includes/excludes and card/profile projection use the same origin and veto rules. Versioned derived indexes allow existing records to match immediately without a source crawl; rollback to code predating these indexes must drop the new origin/veto indexes before restarting the old image.

Catalogue loading retains the last loaded page across title pauses and temporary request failures. Reads have bounded cancellation-aware retries for transient network/HTTP failures; successful focus/poll refreshes clear stale errors. A failed initial load is shown as a load failure instead of an empty search result. CI covers first-load recovery and a successful refresh after an earlier error.
