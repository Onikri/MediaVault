# Сезоны «Монолога фармацевта» и разметка плеера

3 ноября 2026. API v45.

- Обёртка онлайн-плеера больше не ограничена высотой одного видео 16:9: её естественная высота включает список серий. Соотношение 16:9 осталось у самой видеоповерхности и пустого состояния загрузки. Раздел персонажей начинается после полного блока просмотра.
- Унифицированы подписи: «Серия 2»/«2 серия» не повторяются под заголовком карточки. Название серии и примечание о переводе сохраняются.
- Селектор сезонов получает основную телевизионную цепочку по точным ID и связям prequel/sequel из франшизы Шикимори. Фильмы, клипы, альтернативные адаптации и спин-оффы не нумеруются как очередные сезоны. Разделённый сезон сохраняет номер и пометку части.
- Один и тот же список доступен при входе с первого, второго или третьего сезона. Для «Монолога фармацевта»: 54492 → 58514 → 61987 → 62841 (сезон 3, часть 2). «Монолог Маомао» относится к отдельной цепочке.
- Просмотр другого сезона загружает его каталог/метаданные/источники в фоне. Текущий video и его сеанс продолжают работать до явного выбора новой серии. Метаданные витрины меняются по выбранному каталожному ID; источники исходного сезона не подмешиваются.
- Каталожный номер сезона отделён от внутреннего номера провайдера: второй сезон на отдельной странице источника может содержать локальный season=1. Если агрегированный источник предлагает только сезоны 1 и 3, он не используется как подмена отсутствующего второго.
- Подготовленные качества, результаты разбора и превью изолированы по ID произведения, источнику, сезону и серии. Повторное использование одинакового ID студии между сезонами не выбирает старый поток.
- «Порядок просмотра» сначала показывает основную телевизионную историю целиком; остальные произведения франшизы доступны по раскрытию. Известное оригинальное название не заменяется безликим текстом «Название уточняется».

Проверки: Python — граф франшизы с входом из всех четырёх основных записей и исключением спин-оффов; Node — подписи/определение сезона/локальная нумерация источника/отказ от неверного сезона. Chromium — 390 и 1440 px, вход с сезона 3, наличие сезонов 1/2/3, фоновые переходы 3→2→1→3, обновление метаданных, отсутствие нового prepare при простом выборе сезона, точный переход на серию 2 второго сезона, сохранение DOM video и старого потока во время подготовки нового, отсутствие наложения персонажей. Каталог/API и видео браузерных сценариев — контролируемые fixtures; декодирование видео настоящее. Существующая проверка отдельных сезонов провайдера и локальной коллекции сохранена. Production build пройден. ML-инференс не менялся.
