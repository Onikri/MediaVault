# Профессиональный тайпсет и доработка Telea — рабочая инструкция

Статус на 2026-11-15: фазы 1–5 реализованы (`lmt/typeset/`, `telea.ts`, `tone.ts`); фактическое поведение описано в [full-manga-translation.md](full-manga-translation.md). По [руководству Намикуса](https://nmard.yonote.ru/share/06180655-2cd7-45ce-a225-580e8ecb7e16) план изменён: одна основная гарнитура (мысли — наклонным начертанием, крик — тем же шрифтом), ситуативные гарнитуры только для авторского текста, мелких фраз, звуков и записок; переносы — крайняя мера. Не сделано: вертикальный набор, евклидово расстояние и возврат зерна в Telea, выбор набора шрифтов в настройках. Ниже — исходный разбор.

## 1. Как работает сейчас

Конвейер один и тот же на устройстве и на ВМ (ВМ гоняет ту же страницу `lmt/index.html`
в headless Chromium, `server/lmt_runtime.py`):

`lmt/entry.js` → детекция (`upstream/lib/detections`) → OCR → перевод → очистка
(`upstream/lib/inpaint/ladder.ts`) → набор (`upstream/lib/canvas/text-fit.ts`) → PNG/WebP.

Набор (`entry.js:41-47`, `text-fit.ts`):

| Что делает | Почему это не уровень тайпсета |
|---|---|
| Вписывает текст в **прямоугольник текстовой рамки** детектора, pad 8 px | Пузырь — овал; рамка текста уже пузыря. Рамки пузырей (`rtdetr.ts`, класс 0) выбрасываются, если есть текстовые |
| Кегль = максимум, который влез (до 40 px), отдельно для каждой реплики | На одной странице соседние реплики разного размера — главный признак машинного набора |
| Жадный перенос по пробелам; длинное слово режется посимвольно с «-» | Нет правил русского переноса, висячих предлогов, баланса строк, формы «ромб» |
| Один шрифт на всё, всегда 400, строчные | Нет различия речь / крик / мысль / шёпот / авторский текст / звук |
| Всегда чёрная заливка + белая обводка 0.25·кегль, `lineJoin` по умолчанию (miter) | Шипы на обводке; на тёмных пузырях и инверсном тексте неверно; цвет оригинала не учитывается |
| `textBaseline='top'`, интерлиньяж 1.25 | Блок центрируется по em-боксу, а не по видимым глифам — текст визуально «сползает» |
| Нет поворота, нет вертикально-узких пузырей, нет SFX | Наклонные надписи и звуки ставятся горизонтально в рамку |
| Переполнение = ошибка всей страницы (`entry.js:45`) | Одна реплика роняет страницу |

Шрифты (`reader-fonts/catalog.js`, `manifest.json`): Comic Relief 400/700, Pangolin, Neucha, system. Все OFL, локальные.

Очистка: Fast-лестница fill → denoise → Telea (`telea.ts`, вызов `ladder.ts:674`, radius 3);
Quality — LaMa с откатом в Fast. Telea здесь упрощённая:
- расстояние растёт на +1 по 4-соседям, т.е. это обычный BFS, но обслуживается бинарной кучей на `number[]`;
- нормаль берётся из манхэттенского расстояния (ступенчатая);
- из формулы Telea есть только направление и расстояние; **нет** члена уровня `1/(1+|T(p)−T(q)|)` и **нет** градиента яркости `I(q)+∇I(q)·(p−q)` — поэтому градиенты и скринтон замыливаются;
- нет возврата зерна в залитую область.

## 2. Что такое «профессиональный набор» (правила, которые реализуем)

1. Текст вписывается в **форму пузыря**: строки в середине длиннее, сверху и снизу короче; текст занимает ~65–80 % внутренней площади, «воздух» по краям равномерный.
2. **Единый кегль** для одного класса реплик на странице (в идеале на главе); уменьшается только то, что реально не влезает, и не более чем на ~15–20 %.
3. Центр блока = оптический центр пузыря (центроид внутренней области), а не центр рамки.
4. Переносы: по слогам по русским правилам, не оставлять 1 букву, не отрывать предлоги/частицы/союзы (`в, к, с, и, а, не, ни, же, бы, ли`) от следующего слова, тире не в начале строки, не больше одного переноса подряд, последняя строка не из одного короткого слова.
5. Роли и шрифты: речь — комиксный, обычно КАПС; крик — жирный/крупнее; мысль — мягкий/курсив; шёпот — мельче и светлее; авторский текст — спокойный гротеск в прямоугольных плашках; звуки — акцидентный, с поворотом и обводкой; записки/вывески — рукописный/под оригинал.
6. Цвет и обводка: в белом пузыре без обводки; на тёмном — инверсия; поверх рисунка — цвет чернил оригинала + контрастная обводка со скруглёнными стыками.
7. Пунктуация: `…` → `...`, `?!`/`!?` единообразно, кавычки «», тире `—` с неразрывным пробелом, без двойных пробелов, без точки в конце одиночной реплики (опционально).

## 3. Шрифты

Только SIL OFL/Apache (в репозиторий коммерческие нельзя: Anime Ace, CC Wild Words — лицензия Blambot/Comicraft; оставить возможность «свой шрифт» у пользователя).
Кандидаты названы по памяти — **перед добавлением проверить кириллицу (все 66 букв + `ёЁ—«»…`) и записать SHA в `manifest.json`** тем же способом, что и существующие.

| Роль | Сейчас есть | Кандидаты |
|---|---|---|
| speech (речь) | Comic Relief | Balsamiq Sans, Shantell Sans (вариативный, оси неформальности) |
| shout (крик) | Comic Relief Bold | Russo One, Dela Gothic One, Rubik Mono One |
| thought (мысль) | Pangolin | Shantell Sans Italic |
| whisper (шёпот) | Neucha | Amatic SC (узкий) |
| narration (авторский) | — | PT Sans / PT Sans Narrow |
| sfx (звуки) | — | Rubik Wet Paint, Rubik Dirt, Dela Gothic One |
| note (записки, письма) | — | Caveat, Marck Script, Bad Script |

Каталог меняется с «один шрифт» на **набор (pack)**: `{id, label, roles:{speech,shout,thought,whisper,narration,sfx,note}}`.
Наборы: «Классика» (Comic Relief-основа), «Мягкий» (Pangolin/Shantell), «Строгий» (PT Sans-основа).
Файлы подгружаются лениво по ролям, реально встретившимся на странице. Сабсет Latin+Cyrillic, woff2, цель ≤ 60 КБ на файл.
Старое значение `config.font` мигрирует в pack с тем же speech-шрифтом.

## 4. Архитектура

Upstream (`lmt/upstream`, AGPL) не трогаем, кроме Telea (п. 6). Новый собственный модуль, публикуется как integration source:

```
lmt/typeset/
  index.js      typesetPage(ctx, items, {pack, caps, pageW, pageH}) → layouts[]
  region.js     внутренняя область пузыря → построчные интервалы, центроид, признаки формы
  classify.js   роль реплики + цвет/обводка/угол
  hyphen-ru.js  слоговые переносы (алгоритм Христофорова, без зависимостей)
  breaks.js     разбиение на строки под профиль ширин (ДП, штрафы)
  fit.js        подбор кегля + выравнивание кеглей по странице
  draw.js       отрисовка (метрики глифов, обводка, поворот)
  normalize.js  пунктуация, капс, неразрывные пробелы
```

Чистая логика (`hyphen-ru`, `breaks`, `fit`, `classify`, `normalize`) принимает `measure(text, font)` параметром → тестируется в Node без canvas.

### 4.1 region.js — форма пузыря
Вход: очищенный canvas (после inpaint), рамка текста, рамки пузырей из детектора.
1. Протащить `bubbleBoxes` из `rtdetr.ts` наружу (минимальная правка адаптера в `entry.js`/обёртке, не в upstream-логике: вызвать `runRtDetrDetection` напрямую или сохранить класс в `box.kind`). Для CTD — только текстовая рамка + сегментация.
2. Flood fill от центра текстовой рамки по очищенному изображению: порог по яркости «бумаги» (оценка уже есть в `inpaint/mask.ts`/`ring.ts`), ограничение рамкой пузыря (или рамкой текста ×1.6, если пузыря нет), даунскейл до ≤ 160 px по большей стороне — это миллисекунды даже на телефоне.
3. Эрозия на отступ (≈ 8 % меньшей стороны, минимум 4 px) → для каждой строки пикселей интервал `[xL, xR]`.
4. Выход: `rows[]`, `centroid`, `area`, `solidity` (площадь / площадь выпуклой оболочки), `rectangularity`, `touchesEdge`.
5. Если заливка «вытекла» (площадь > рамки пузыря или > 25 % страницы) или фон не плоский — откат к эллипсу, вписанному в рамку (для text_bubble) или к прямоугольнику (text_free).

### 4.2 classify.js — роль
Признаки без модели:
- `kind` детектора: `text_free` → sfx/narration/note; `text_bubble` → speech-семейство;
- форма: `solidity < 0.85` (шипы) → shout; `rectangularity > 0.9` → narration; волнистый/облачный контур — thought (низкий приоритет, легко ошибиться → по умолчанию speech);
- оригинал: высота глифов относительно медианы по странице (> 1.4× → shout, < 0.75× → whisper), толщина штриха из ink-маски, угол (PCA по ink-маске; |угол| > 7° → поворот), цвет чернил и бумаги (медианы по маске/кольцу) → инверсия и обводка;
- текст перевода: только `!`/`?!` и ≤ 3 слов усиливает shout; `(...)` → thought; text_free из ≤ 2 слов без пробелов-предложений → sfx.
- VLM-режим (`lmt/vision.js`): опционально попросить поле `style` на реплику; Hy-MT2 не трогаем — у него официальный prompt-контракт.

Результат: `{role, angle, fill, stroke, strokeWidth, caps}`. Ошибка классификации должна деградировать в `speech`, а не в экзотику.

### 4.3 breaks.js + hyphen-ru.js
- Токены: слова, с прилипанием коротких предлогов/частиц и тире через неразрывный пробел (`normalize.js`).
- Для заданного кегля и числа строк `n`: ширины строк берутся из `rows` (минимум интервала по высоте строки), блок центрируется по вертикали на центроиде.
- ДП по точкам разрыва, стоимость = Σ (незаполненность строки относительно её доступной ширины)² + штрафы: перенос слова (большой), два переноса подряд (очень большой), последняя строка из одного слова ≤ 3 букв, строка шире доступной (запрет).
- Перенос разрешён только если без него кегль падает ниже порога класса; обрывок ≥ 2 букв с каждой стороны.
- Перебор `n` от 1 до ⌈высота/интерлиньяж⌉, берётся минимальная стоимость.

### 4.4 fit.js — кегль
1. Для каждой реплики бинарным поиском найти `maxSize`, при котором есть допустимое разбиение.
2. Базовый кегль роли на странице = min(нижний квартиль `maxSize` этой роли, кегль из высоты оригинальных глифов × коэффициент языка (JP ≈ 0.85, EN ≈ 1.0), потолок 3.2 % ширины страницы).
3. Реплика получает базовый кегль; если не влезает — свой `maxSize`, но не ниже `0.8·base`; ниже — разрешить переносы, затем расширить область до рамки пузыря; затем минимум 9 px (в пикселях экрана при типичной ширине) и предупреждение в `warnings`, **не исключение**.
4. Интерлиньяж: 1.08 для капса, 1.18 для строчных; считается от реальных `fontBoundingBoxAscent/Descent`.

### 4.5 draw.js
- `textBaseline='alphabetic'`; вертикальное центрирование по `actualBoundingBox*` первой и последней строки.
- `lineJoin='round'`, `miterLimit=2`; обводка только когда нужна (вне пузыря / низкий контраст), ширина ≈ 0.12–0.18·кегль, рисуется одним проходом под всеми строками.
- Поворот: `translate(centroid) → rotate(angle)`; раскладка считается в повёрнутой системе.
- `ctx.fontKerning='normal'`; для капса `letterSpacing` +0.01em (если поддерживается).
- Жирность только при наличии настоящего начертания (никакого synthetic bold).
- Страницы уже 900 px: набирать на canvas ×2 и отдавать ×2 (решить отдельно — меняет размер кэша; по умолчанию выкл.).

### 4.6 Интеграция
- `entry.js:41-47` заменить на `typesetPage(...)`; в результат — `typesetting:{engine:'shaped-cyrillic-v3', pack, layouts:[{index, role, fontSize, lines, hyphens, shrunk}]}`.
- `src/manga-translation.js`: `TRANSLATION_VERSION` 4→5, `typesetter:'shaped-cyrillic-v3'`, поле `font` → `fontPack` (+ миграция), `caps` в `resultConfig` (входит в ключ кэша). Проверить, что ключ серверного кэша в `server/lmt_service.py` включает те же поля.
- `src/LmtSettings.jsx`: выбор набора шрифтов и переключатель КАПС — внутри существующего блока настроек, без новых карточек.
- `src/TranslationLayer.jsx` + `manga-reader.css`: текстовый слой использует speech-шрифт набора.
- Регионы в ответе (`regions[]`) дополнить `role` — пригодится списку реплик под страницей.

## 5. Доработка Telea (`lmt/upstream/lib/inpaint/telea.ts`, с пометкой «MediaVault change» и записью в `THIRD_PARTY.md`)

Скорость (результат должен остаться эквивалентным в пределах шума):
1. Куча → послойный BFS на `Int32Array` (расстояние и так целочисленное) — O(n) без аллокаций.
2. Таблица весов `1/(1+d²)` и `1/√d²` для окна (2r+1)² один раз; убрать замыкания `inBounds/idxOf`, работать в ограничивающем прямоугольнике маски + r.
3. Переиспользуемые буферы между регионами страницы.

Качество (каждый пункт отдельно меряется, включается только при выигрыше):
4. Евклидово расстояние (Felzenszwalb, два прохода) вместо манхэттенского → гладкие нормали, меньше «крестов».
5. Вернуть недостающие члены Telea: вес уровня и градиент яркости известных соседей (с ограничением, чтобы не было выбросов).
6. Новая ступень `tone` перед Telea для скринтона: по кольцу оценить период/направление растра (автокорреляция на яркости, окно ≤ 64 px); если пик уверенный — заполнять копированием со сдвигом на k·период из известной области, швы сгладить 1 px. Отклоняется той же метрикой `regionDeclines`.
7. Возврат зерна: добавить шум с σ из `pageNoiseSigma` в залитую область (детерминированный seed по координатам, чтобы кэш был воспроизводим).

Измерение: `scripts/benchmarks/run-inpaint.py` (ошибка внутри маски, изменение снаружи, мс) до/после на тех же масках + отдельные кейсы скринтона и градиента в `manga_cases.py`. Замер времени — на WASM CPU и на телефоне, отдельно от ВМ.

## 8. Риски

- Flood fill вытекает из незамкнутых пузырей → обязательный откат к эллипсу и ограничение рамкой.
- Ложная классификация роли заметнее, чем её отсутствие → консервативные пороги, по умолчанию speech.
- КАПС увеличивает ширину текста ~на 15 % → учитывать в базовом кегле; оставить переключатель.
- Смена версии набора инвалидирует кэш готовых страниц (устройство и ВМ) — ожидаемо, один раз.
- Изменение порядка обхода в Telea меняет пиксели → сравнивать по метрике, а не побайтно.
