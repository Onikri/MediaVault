# Украинский интерфейс, украинский контент, фильмы/сериалы и ранобэ с нейроозвучкой ролей

План от 8 ноября 2026. Ветка `claude/uk-ranobe-tts` от `main` (53ce70d).

## Что просили

1. Переключение интерфейса на украинский в настройках.
2. Фильтр парсера по языку контента: украинские аниме, манга, ранобэ, фильмы и сериалы.
3. Фильмы и сериалы из баз плееров (Kodik, Sibnet и другие, озвучка LostFilm).
4. Нормальные сайты фан-переводов.
5. Читалка ранобэ с лёгкой, но качественной нейроозвучкой прямо в браузере.
6. Семантический разбор текста: персонажи, реплики, эмоции; разные голоса и окраска; одна кнопка «Слушать».

## Разведка: что проверено руками

Проверки сделаны с ВМ Oracle (Германия) — именно оттуда работают парсеры.

### Видео (UA)

| Источник | Доступ с ВМ | Что даёт |
|---|---|---|
| AniHub `api.anihub.in.ua` | 200, JSON | Каталог аниме с `mal_id`, `has_ukrainian_dub`, студии |
| Hikka `api.hikka.io` | 200, JSON | Украинская база аниме/манги/ранобэ: `title_ua`, `synopsis_ua`, `translated_ua`, ссылки «где читать» |
| Mikai, AniUA, AniFlow, Eneyida, UASerials, UAFix, UASerial | 200 | DLE-каталоги с плеерами Ashdi / Tortuga / Moon |
| AniTube | **403 Cloudflare** с ВМ | Плейлист `/engine/ajax/playlists.php` идеален, но обход защиты не делаем → только как недоступный источник |
| Ashdi `ashdi.vip/vod/N` | 200, в странице `index.m3u8` | Публичный HLS; с устройства пользователя — геоблок, поэтому поток идёт через ВМ |
| Moonanime, Tortuga | ответы зависят от страны/реферера | Разбираются при реализации |

Озвучки сейчас **явно выкидываются**: `src/watch-session.js` `orderedVoices` убирает `language==='uk'`, `server/source_discovery.py` `voice_suggestions` берёт только `ru|und`.

### Фильмы и сериалы

- Токена Kodik API на сервере нет. Аниме идёт через сайты, которые встраивают плеер Kodik, — так же сделаем и фильмы.
- Публичный балансер плееров Kinobox (рабочее зеркало `fbphdplay.top/api/players?imdb=…|kinopoisk=…`) по ID отдаёт плееры **Alloha, Collaps, Veoveo, Turbo** с названиями озвучек. В ответах есть «LostFilm», «Украинский», «Так Треба Продакшн», «AMC (укр)». Alloha уже поддерживается сервером. Collaps добавляем отдельным разборщиком.
- LostFilm: каталог публичный, их собственный плеер требует вход в аккаунт. Решение пользователя: каталог LostFilm + озвучка LostFilm в плеерах, без аккаунта.
- Sibnet: `video.sibnet.ru` отвечает **403** с ВМ. Остаётся как плеер там, где сайт его встраивает; каталога Sibnet не будет (честно отмечаем в источниках).
- Существующий `server/kodik_api.py` (по токену) остаётся: если владелец введёт токен, база Kodik фильмов/сериалов подключится автоматически.

- Honey Manga `data.api.honey-manga.com.ua` — JSON API, 2155 тайтлов.
- Zenko `api.zenko.online` — JSON API.
- Mangarama, UAManga, manga.in.ua — HTML, доступны.

### Ранобэ (текст)

Эталон — плагины LNReader (MIT, активно поддерживаются): `ranobehub`, `jaomix`, `ranobeme`, `ruranobe`, `novelTL`, `renovels`, `bakainua`, `smakolykytl`.

- С ВМ работают RanobeHub (`/api/search`, `/api/books/{id}/chapters`, `/api/chapters/{id}`), Jaomix, Ranobe.me, Rulate и baka.in.ua (украинский).
- Smakolyky (украинский) имеет JSON API.
- RanobeLib с ВМ **геоблокирован** (DDoS-Guard), Ranobes отвечает 429/«одну минуту», RoyalRoad закрыт Cloudflare. Эти три помечаем недоступными и не обходим.

### Нейроозвучка в браузере

Выбор: **Supertonic 3** (Supertone, апрель 2026).

- 31 язык, включая `ru` и `uk`.
- Около 99 млн параметров, ONNX, без фонемайзера: текст идёт через NFKD и таблицу символов.
- 10 готовых голосов (M1–M5, F1–F5), управление скоростью и числом шагов, теги `<laugh>` `<breath>` `<sigh>`.
- INT8-сборка `soniqo/Supertonic-3-ONNX-INT8` весит 102 МБ вместо 398 МБ, пиковая память примерно 330 МБ.
- Вес под OpenRAIL-M: обязательна пометка, что звук синтезирован, и запрет имитации реальных людей.
- Есть эталонный JS-код на `onnxruntime-web` (архив `supertone-oss-archive/supertonic`, MIT).

Альтернативы и почему не они:

- Kokoro: нет русского и украинского.
- Piper: 60 МБ на один голос одного языка, а 10 голосов на два языка — около 600 МБ, без эмоций.
- Chatterbox-multilingual: 0.5B, тяжёл для браузера и без украинского.
- Qwen3-TTS: нет браузерной сборки и нет украинского.
- Silero: только PyTorch, лицензия NC.

Выбор подтверждается собственным замером, а не только обзорами (этап 0).

Эмоции: в Supertonic нет отдельного вектора эмоций, поэтому окраска собирается из того, что модель реально умеет:

- темп;
- паузы;
- громкость;
- теги смеха, вздоха и дыхания;
- смесь стилей голоса для «шёпота» и «крика»;
- интонационная пунктуация.

Это честное ограничение, и оно записывается в документацию.

### Разбор ролей и эмоций

Делается через существующий Google-канал проекта: личный ключ на устройстве или слоты ключей на ВМ (`/reader/google/generate`), модели из `src/google-models.js`. Без ключа работает эвристика: русские и украинские реплики через тире и «ёлочки», глаголы речи («сказал/сказала», «відповіла»), род по окончанию глагола.

## Архитектура решения

### 1. Украинский интерфейс (без переписывания 300 файлов)

- `src/i18n/` — слой перевода DOM.
  - Вешает `MutationObserver` на текстовые узлы и атрибуты `aria-label`, `title`, `placeholder`, `alt`.
  - Порядок поиска: точное совпадение, затем шаблон с числами, затем замена известных фраз с проверкой границ слов.
  - Кэш результатов в LRU.
  - Поддеревья с `translate="no"` не трогает: так защищены текст книг, названия тайтлов, описания, чат, тексты песен, переводы манги.
- `scripts/i18n-extract.mjs`.
  - Через AST (rollup `parseAst`) собирает все русские строки интерфейса из `src/` (~3400) и сообщения сервера (~1000).
  - Пропускает промпты для моделей.
  - Пишет `src/i18n/ru-strings.json`.
- `src/i18n/uk.json` — ручной перевод на украинский: целиком, без машинного «автоперевода».
- Тест покрытия: каждая извлечённая строка имеет перевод. Отдельно проверяются плюрали, месяцы и дни недели.
- Даты: все `toLocale*('ru-RU')` переводятся на общий `uiLocale()`.
- `<html lang>` переключается.
- Переключатель «Мова інтерфейсу / Язык интерфейса» ставится в Пульт → Личное → Оформление.
  - Значение хранится в `localStorage` устройства.
  - Смена применяется сразу, без перезагрузки: слой проходит DOM.

### 2. Язык контента

- Общий параметр `contentLanguage: 'all' | 'ru' | 'uk'`.
- В UI это фильтр «Язык контента» рядом с фильтрами источников и озвучек.
- Сервер:
  - Голосам проставляется `language` по названию (украинские буквы, «укр», «UA», известные украинские студии).
  - Discovery принимает `contentLanguage`.
  - Манга получает язык `uk` (`suwayomi_bridge.LANGUAGES`, `manga_discovery`, `manga_sources`).
- `orderedVoices` больше не выкидывает `uk`. Он сортирует по выбранному языку: при «Українська» украинские озвучки идут первыми.

### 3. Новые серверные адаптеры

- Видео UA:
  - `server/ua_video_sources.py`: AniHub (каталог + серии), Eneyida, UASerials, UAFix, Mikai как DLE-адаптеры в `SITES`.
  - Разборщики плееров Ashdi / Tortuga / Moon в `Resolver.player`.
  - Ashdi отдаёт HLS через уже существующий relay ВМ.
- Фильмы/сериалы:
  - `server/kinobox_source.py`: IMDb или Кинопоиск → плееры Alloha / Collaps, все озвучки с языком.
  - Collaps-разборщик с выбором аудиодорожки по озвучке.
  - Kodik по токену, если он появится.
- LostFilm: `server/lostfilm_catalog.py` — публичный каталог сериалов и лента новых серий. Кнопка «Смотреть в озвучке LostFilm» выбирает озвучку LostFilm из найденных плееров.
- Метаданные UA: Hikka как провайдер в `metadata_catalog.py`. Даёт украинские названия и описания при украинском интерфейсе и ссылки «где читать / смотреть» по-украински.
- Манга UA: Honey Manga и Zenko как `MangaSite` с API. Mangarama и UAManga — HTML.
- Ранобэ: `server/ranobe_sources.py`.
  - Общий интерфейс `search / chapters / chapter_text` и чистка HTML до абзацев.
  - Сайты: RanobeHub, Jaomix, Ranobe.me, Rulate, baka.in.ua, Smakolyky.
  - API: `POST /ranobe/search`, `POST /ranobe/inspect`.
  - Текст главы отдаётся через `/online/prepare` с новым `kind: text`.

### 4. Ранобэ-читалка

- `WorldTitlePage`: для ранобэ вместо заглушки «Автоматический источник не подключён» появляется выбор источника и глав. Используются существующие `ChapterChooser` и `selectChapters`.
- `BookReader` получает источник `chapters`: глава грузится с сервера, следующая подгружается заранее. Прогресс сохраняется по главе и символу.
- Абзацы и предложения рендерятся с id, чтобы можно было подсвечивать текущую реплику.

### 5. Нейроозвучка

- `src/tts/supertonic.worker.js` — четыре ONNX-сессии в Web Worker.
  - Сначала пробуется WebGPU, при неудаче — WASM.
  - Шум генерируется с фиксированным seed: одна реплика всегда звучит одинаково.
- `src/tts/model.js`: загрузка весов по закреплённой ревизии HF с проверкой SHA-256 и Cache Storage, по шаблону `src/pause-depth-cache.js` и `model-folder.js`. Загрузка только после явного согласия, с показом размера.
- `src/tts/player.js`: очередь синтеза на N реплик вперёд, `AudioContext`, MediaSession, пауза музыки и видео через события.
- `src/tts/cast.js`: голоса персонажей.
  - Персонажу подбирается голос по роду, возрасту и описанию.
  - Главные герои получают уникальные голоса, в том числе смеси двух пресетов, если пресетов не хватает.
  - Рассказчик — отдельный голос.
  - Таблицу ролей можно редактировать.
- `src/tts/roles.js`: разбор главы.
  - Сначала эвристика (мгновенно).
  - Затем, если есть ключ, уточнение через Gemini/Gemma строгим JSON: персонажи, `segments[{i, speaker, kind, emotion, intensity, tags}]`.
  - Реестр персонажей переносится между главами.
  - Кэш в IndexedDB по книге.
- `src/tts/emotion.js`: эмоция → параметры синтеза (темп, шаги, громкость, паузы, теги).
- UI: кнопка «Слушать» в шапке читалки и мини-панель в `status`. В ней: play/пауза, ±предложение, скорость, «Роли». Текущая реплика подсвечивается, страница перелистывается автоматически.
