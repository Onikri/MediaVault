# Японские оригиналы, корейская манхва и вебтуны

Добавлены языки `ja` и `ko` во всём пути: API поиска/проверки, фильтры импорта,
опубликованные главы, CBZ, язык файла в библиотеке, онлайн-чтение и переводчик.
Язык глав независим от формата произведения. Манга, манхва, маньхуа и вебтуны
остаются в общей категории `manga`, а поле `format` и режим чтения сохраняются
в метаданных. Русский интерфейс и русское каталожное название сохраняются.

## Источники

| Источник | Язык | Реализация |
| --- | --- | --- |
| MangaRaw | JA | Публичный JSON поиска, тайтла, глав и страниц; явные опубликованные шаблоны изображений |
| Sen Manga | JA | Публичный directory, сведения о тайтле, chapterList и read/pages |
| Naver Webtoon | KO | Публичные search/article API, HTML опубликованной главы |
| Naver Best Challenge | KO | Отдельный авторский каталог Naver |
| Naver Challenge | KO | Отдельный авторский каталог Naver |
| Toonkor | KO | HTML поиска/глав, опубликованный base64-список изображений без исполнения JavaScript |
| MangaDex | RU/EN/JA/KO | Расширены языковые фильтры, оригинальный язык и формат сохраняются |

Контракты сверены с [Keiyoushi extensions-source, Apache-2.0](https://github.com/keiyoushi/extensions-source/tree/6768cbc2049c5e07d67ea1ac667af73f9737596a):
`src/ja/mangaraw`, `src/ja/senmanga`, `src/ko/navercomic`, `src/ko/toonkor`.
Собственные Python-адаптеры не исполняют Android-код и не используют аккаунты
источников. Публичные API разрешены только по конкретным хостам и путям;
адреса авторизации и приватные API не разрешаются.

Поиск сравнивает полные названия и известные синонимы, предпочитая японские
или корейские названия для соответствующего источника. Похожие названия
не считаются доказанным совпадением. Каталог Sen Manga иногда игнорирует
поисковый параметр: проверяется до пяти опубликованных страниц directory,
после чего всё равно применяется точное сопоставление. Новые языки и форматы
разделяют кэш поиска. Общий бюджет поиска — 18 секунд, до 12 IO-задач
параллельно, чтобы дополнительные источники не образовали длинную очередь.

Текущий подтверждённый домен Toonkor — `toonkor7.org`; сохранены только
проверенные старые адреса `toonkor0.org` и `toonkor2.org`. Произвольное
перенаправление на другой источник возвращает ошибку. Корейские пути
кодируются перед отправкой в HTTP-заголовке Referer. Rawkuma был изучен,
но проверка не подтвердила ожидаемый JSON/HTML читалки; адаптер не добавлен
в качестве якобы работающего источника.

Платные/заблокированные записи Naver исключаются. Если читалка не выдаёт
изображения без входа, покупки или проверки браузера, возвращается причина.
URL глав не вычисляются из общего количества. Номера `0` и дробные значения
сохраняются. У Naver параметры `titleId`/`no` входят в идентификатор файла:
разные тайтлы и выпуски не склеиваются в Drive.

## Фактическая проверка 27 октября 2026

Результаты и SHA-256 первого проверенного изображения записаны в
[`benchmarks/manga-raw-live-2026-10-27.json`](benchmarks/manga-raw-live-2026-10-27.json).
Проверены настоящие production-адаптеры и загрузка изображения по HTTPS:

| Источник | Опубликованные записи | Страницы проверенной главы |
| --- | ---: | ---: |
| MangaRaw, «Дандадан» | 249 | 68 |
| Sen Manga, «Дандадан» | 249 | 68 |
| Naver, «Возвращение Хуа Шань» | 186 | 147 фрагментов вертикальной ленты |
| Toonkor, тот же тайтл | 188 | 22, проверен специальный выпуск |

Это записи источника, включая экстра, а не выведенное число основных глав.
Проверена одна глава и первое изображение каждого источника. Все изображения
не скачивались и в репозиторий не помещались. Доступность зависит от времени
и региона. Это проверка из CaaS, не утверждение об установке на Oracle.
Best Challenge и Challenge имеют отдельные контрактные тесты поиска;
сквозной замер главы выполнен для основного Naver Webtoon.

Тесты дополнительно проверяют языковое разделение, публичные адреса,
закрытые главы, зацикливание пагинации, порядок изображений в CBZ,
идентичность исходных байтов и сохранение языка/формата при импорте.
Браузерные проверки охватывают JA/KO импорт и манхву на экранах 320/1280 px.

## Читалка и установка

Для манхвы используется вертикальная лента с направлением слева направо;
для японского оригинала предлагается справа налево. Явные настройки
пользователя имеют приоритет. Переводчику передаётся действительный исходный
язык; лёгкий EN-детектор не применяется к CJK. Инференс Google для новых
языков в этом изменении не замерялся.

Нужен backend версии **12**. Старая версия продолжает RU/EN импорт;
JA/KO и фильтр формата в интерфейсе отключены до обновления. Установка
использует существующий `deploy/oracle/update-from-cloud-shell.py` с полным
SHA проверенного коммита. Он обновляет существующую VM, сохраняет конфигурацию
и очередь, делает резервную копию и проверяет новую версию. Новые VM,
платные сервисы, ресурсы и ключи сторонних источников не требуются.
