# Libre Manga Translator: проверка интеграции

Проверен mrdhnto/libre-manga-translator, commit 39a95be1890e2ea3e227052976bbaf576a8eb7b3 (1.0.3).
Это WXT/Svelte расширение браузера, а не Python-сервис или npm-компонент React.
Лицензия стабильной версии AGPL-3.0-or-later. Перенос должен сохранять лицензию,
атрибуцию и доступ к соответствующему исходному коду. Код пока не скопирован в приложение.

## Варианты

| Размещение | Что работает | Ограничения |
| --- | --- | --- |
| Десктоп, WebGPU | RT-DETR/ComicTextDetector, PaddleOCR/другие OCR, WebLLM, inpaint и typesetting | Первичная загрузка крупных моделей; WebLLM требует доступный WebGPU, память GPU и совместимые модели |
| Android/планшет | OCR через WASM, часть GPU-инференса на совместимых устройствах | Возможности WebGPU и память сильно различаются; нужен явный запасной вариант |
| Oracle ARM CPU | Отдельный self-hosted LLM (Ollama/OpenAI-compatible) для перевода текста | Сам LMT не содержит такого сервера; OCR в его API-режиме остаётся в браузере. 2 OCPU нельзя считать быстрым сервером для многостраничного LLM-перевода |
| Смешанный | Локальные detection/OCR/typesetting, текст в собственный LLM | Нужны API адаптер, ограничения очереди и проверенная ARM-модель; Drive-ключи в LMT передавать не требуется |

Для дискретного GPU предпочтителен первый вариант. Полноценный web-port требует
замены browser.runtime/storage и offscreen messaging, управления загрузками моделей,
переноса настроек/редактора, настройки ONNX WASM assets и интеграции с расшифрованными Blob.
Общая точка запуска pipeline находится в src/entrypoints/offscreen/main.ts.
Серверная интеграция без этого переноса не заменит текущие detection/OCR/inpaint.
Gemini и внешние платные API для MediaVault не включаются.

## Проверки перед объявлением готовности

1. Проверить detection → script gate → OCR → translation → inpainting → typesetting на реальных EN/JP/KR страницах.
2. Проверить реальные загрузки весов и восстановление кэша, ограничение WASM threads для GitHub Pages без COOP/COEP.
3. Проверить WebGPU на физическом desktop/Android; эмуляция размера экрана не подтверждает GPU-совместимость.
4. Сохранить оригинальную страницу, изолировать лицензируемую сборку и предоставить исходники.

Статус: исследование и выбор архитектуры подготовлены; полный web-port LMT не внедрён.
Текущий Oracle EN→RU pipeline не переименован в LMT.
