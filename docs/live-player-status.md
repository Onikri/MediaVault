# Проверка плееров на Oracle VM

Проверено 25 октября 2026 года с существующей VM `mediavault-import`.
Команда: `python scripts/check-live-players.py --catalog --report <private-file>`.
Использовался изолированный контейнер без тома пользовательских данных и без
Google/OAuth. Для каждого успешного плеера прочитаны 1024 байта медиаданных
максимального найденного качества. Это проверка примеров, а не всех тайтлов.

| Плеер | Живой результат | Разрешения в проверенном примере |
| --- | --- | --- |
| Aniboom | Медиаданные получены | 1080, 720, 480, 360 |
| CVH | Медиаданные получены | 1080, 720, 480, 360, 240, 144 |
| Kodik | Медиаданные получены, включая современный serial | 720, 480, 360 |
| Animedia | Медиаданные получены | 720, 360 |
| AniLiberty | Медиаданные получены | 1080, 720, 480 |
| VK | Медиаданные получены | 720, 480, 360, 240, 144 |
| Sibnet | Публичный пример отвечает HTTP 403 | Не подтверждены |
| SovetRomantica | Исторический формат проходит сохранённые ответы; старый домен сменил владельца | Живое воспроизведение не подтверждено |
| Jut.su | Проверенная страница закрыта видимым JutPlus | Не подтверждены |
| Alloha | Нужен действующий публичный iframe для живой проверки | Не подтверждены |

Поиск точного «Дандадан», MAL 57334, 2024 вернул 49 групп переводов и три
страницы источников. Некоторые сайты не ответили, поэтому это неполный результат.
Названия ненайденных переводов и отсутствующие качества не выдумываются.

Сохранённые ответы восьми плееров из `anime-dl-core` проверяют формат парсеров;
они не доказывают текущую доступность домена. Alloha/Jut.su дополнительно имеют
тесты исполнения JavaScript в изолированном браузере. Платные ограничения,
CAPTCHA и авторизация не обходятся. Подписанные медиассылки остаются на сервере;
публичный отчёт их не содержит.
