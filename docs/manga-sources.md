# Русскоязычная манга и оценки

Проверено 25 октября 2026 года. MediaVault использует собственные Python-адаптеры:
HTML поиска, опубликованные ссылки глав, изображения читалки. Android-приложения,
аккаунты и наборы токенов сторонних загрузчиков на сервер не устанавливаются.

Селекторы сверены с настоящими HTML-страницами; Android-код не переносился целиком.

Числа разных источников не складываются: отличаются нумерация, экстра и варианты
перевода. URL глав не вычисляются из общего количества. Платные главы, запросы
авторизации и проверки браузера возвращают понятную ошибку.

Выбранная манга сохраняет точный MAL ID, тип `manga`, русское название и синонимы.
Поиск проверяет название и известный год; выбранная страница сверяется повторно.
Аниме и манга с одинаковым числовым ID остаются разными сущностями.

Поддержаны глава 0, дробные номера, тома и опубликованные команды перевода.
«Одна глава» выбирает конкретный URL: одинаковый номер в двух томах не становится
двумя импортами. Без выбора переводчика остаётся один вариант пары «том + глава».

Oracle скачивает до трёх страниц параллельно, сохраняет порядок в CBZ, делает
превью и загружает зашифрованные блоки в существующий Drive. При импорте устройство
передаёт только задание. При чтении глава загружается и расшифровывается браузером.
Ограничения: 500 страниц и 1 ГБ на главу, 1000 выбранных глав на задание.

## Оценки и проверки

Shikimori, MyAnimeList через Jikan, AniList и Kitsu связываются по MAL ID и типу.
Для Kitsu проверяется связь `mappings`, для AniList — `idMal`. Шкалы приводятся к
10 баллам с сохранением оригинала и числа голосов. Недоступная платформа не получает
выдуманную оценку. Кэш успешного ответа — 6 часов, ошибки — 90 секунд. Оценки
сохраняются в зашифрованном профиле тайтла.

Проверяются: современные форматы HTML, платная заглушка, глава 0 и 12.5,
CBZ → AES-GCM → тестовый Drive → точные байты страниц, повторный импорт,
браузерное чтение и переход между главами, разные аккаунты, выбор тома и диапазона,
различие рейтингов манги и аниме.
