# Дополнительные разделы тайтла и запуск видео

3 ноября 2026. API v44.

## Интерфейс

- Витрина на desktop занимает один экран. Отступ над единой группой контента рассчитывается по фактической высоте текста и информации, в таблице убран унаследованный двойной промежуток. На телефоне контент идёт естественным потоком. Полный текст описания доступен отдельной кнопкой.
- Карточка персонажа показывает только опубликованные параметры из Шикимори/MyAnimeList, сохраняет ссылки на источники. Семья, статус и дебют раскрываются отдельно как возможные спойлеры. Неизвестные данные не генерируются; произведения с участием персонажа не выдаются за точный номер серии.
- Музыкальные строки получили обложку тайтла, OP/ED, исполнителя, серии, действия и очередь всего списка. Карточка песни содержит сведения об исполнителях и ссылки на записи. Это обложка аниме, не выдуманная обложка альбома.
- Кадры открываются в просмотрщике: стрелки, увеличение, fullscreen, Escape. Оригинал выбранного кадра запрашивается по требованию.
- Трейлер использует существующий React-плеер. Сервер проверяет принадлежность ролика выбранному MAL ID, включая YouTube ID в Jikan. Ошибка источника видна с возможностью повтора; готовый ролик поддерживает Range. При требовании YouTube подтвердить, что IP ВМ не является ботом, сервер разрешает официальный iframe только с проверенным по каталогу ID того же ролика; произвольные URL не принимаются. Запрет встраивания/региональное ограничение владельца ролика остаются видимыми ошибками официального плеера.
- Календарь показывает все доступные даты, позволяет раскрывать следующие серии/страницы каталога и выбирать месяц. График оригинального выпуска не подменяется графиком озвучки.

## Подготовка видео

- Найденные озвучки отдаются по мере ответа провайдеров. Фоновые запросы одного тайтла объединяются; браузер опрашивает состояние с паузой 600 мс. Сохраняется ограниченный индекс публичных названий/стабильных страниц, без CDN-ссылок серий, cookies и заголовков авторизации.
- Короткий RAM-кэш разобранных источников (20 с) и манифестов (15 с), singleflight, ограничение очереди и принудительное обновление при повторе. Явный срок подписанной ссылки сокращает TTL. Каждому просмотру выдаётся отдельная новая capability.
- Публичные источники используют общий TCP/TLS-пул, но отдельные Sessions/cookies. Доступ к Google и его авторизация в этот пул не входят. Опубликованные HLS-качества проверяются параллельно, не по одному.
- HLS начинает загрузку с сохранённой позиции; ABR, доступные качества, отдельное аудио, субтитры и существующие ограничения буфера сохранены.
- Drive: подтверждённая сессия Service Worker не пересылает весь каталог повторно при каждом запуске; изменение токена/ключа/каталога или контроллера требует новой синхронизации. Одновременные Range делят загрузку зашифрованного блока; в RAM остаются максимум четыре блока ciphertext на 60 с. Запись ciphertext в CacheStorage больше не задерживает отдачу первых байтов. Отмена одного Range не отменяет другого. Расшифрованные данные на диск не записываются.
- При переключении файлов коллекции React-плеер не пересоздаётся через key серии.

## Проверки

60 соответствующих Python-проверок: изоляция/TTL/singleflight, независимость сессий, реестр источников, опубликованные качества/DRM, progressive discovery, факты персонажей и принадлежность трейлера. Node-проверки проверяют настоящую AES-GCM расшифровку и точные Range, совместную загрузку и отмену, модели плеера/сессии/метаданных. Production build пройден.

Chromium: витрина 390/768/1024/1366/1440 px, включая высоту 768 px и богатую таблицу; обратная SVG-маска, параллакс, сохранение video при прокрутке и reduced motion. Дополнительные разделы проверены на 390/1440 px: модалки, спойлеры, очередь песен, весь календарь, просмотр кадров и декодирование нативного трейлера. Внешние API и видео в этих браузерных сценариях являются контролируемыми fixtures.

На ВМ до обновления реальная подготовка первой серии My Hero Academia / AniLiberty: 336 и 334 мс, HLS-манифест HTTP 200. После обновления холодный запрос: 396 мс (разбор источника 252, манифест 135); повторный: 10 мс (кэш разбора, подготовка 6 мс). Обе выдачи — HTTP 200 и свежие capabilities. Живой запрос персонажа 40882 вернул Эрена Йегера, опубликованные возраст/рост/вес и 27 произведений за 2359 мс. Скорость всех сторонних источников и полный запуск с учётом сети пользователя этим замером не гарантируются. Живая библиотека Google Drive пользователя недоступна тестовой сессии: её протокол проверен на реальной криптографии и многоблочных файлах, не заявляется живой замер Drive. ML-инференс в этой задаче не менялся и не имитировался.
