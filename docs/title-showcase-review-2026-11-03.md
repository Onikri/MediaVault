# Витрина, источники видео и разметка плеера

- Вместо YouTube iframe фон получает видео по точному MAL ID через
  `/backgrounds/{id}`. AnimeThemes предоставляет реальные OP/ED этого аниме;
  исключены чужие ID, NSFW и отмеченные спойлеры. Для фильмов без таких роликов
  проверяются проморолики этого же тайтла. Недоступный ролик не считается
  успешно загруженным видеофоном.
- ВМ готовит беззвучный H.264 MP4, максимум 720p/24 fps, до 45 секунд.
  Холодная подготовка асинхронная; интерфейс показывает её состояние.
  Готовые файлы сохраняются в `.codex-local/backgrounds` и переживают перезапуск.
  При занятых слотах клиент повторяет запрос; основное видео не ждёт фон.
- Постер, описание и информация объединены в нижнюю сетку витрины.
  Фон и три передних слоя имеют разные скорости прокрутки; эффект обратим.
  Reduced motion отключает движение и автоматический запуск фона.
- SVG-апертура плеера больше не остаётся навсегда раскрытой после первого
  прохода. Прокрутка не пересоздаёт media element и не останавливает его звук.
- Онлайн-тайтлы получают адрес `#watch=kind:provider:id`, пригодный для
  перезагрузки и передачи ссылки. Смена тайтла начинает прокрутку сверху.
  Сохраняется только публичная каталожная карточка, не токены воспроизведения.
- Озвучка и качество находятся внутри настроек плеера, включая экран до запуска.
  Безымянные результаты не выдаются за отдельные студии. Именованные озвучки
  с одной серией сохраняются.
- `skip_segments` реального парсера Kodik проходят через `/online/prepare`
  в плеер. Приоритет: ручная отметка, тайминг выбранного источника, AniSkip.
- LRCLIB сначала получает структурированный поиск `track_name/artist_name`,
  затем общий запрос. Добавлен резервный источник обычного текста Lyrics.ovh.
  Обычный текст не получает выдуманных временных меток. AMLL проверяется
  также после пустого ответа/ошибки основного поиска.

## Проверка

Python: 47 проверок API/каталогов/идентичности, включая передачу таймингов
Kodik и структурированный поиск `the WORLD — NIGHTMARE`. Node: 30 проверок
плеера, текстов, предпочтений и адресов тайтлов. Браузер: витрина на ширинах
390/768/1440, обратная SVG-анимация, приостановка фона, сохранение media element;
плеер на 390/1440 с декодированием HLS, отдельным звуком, настройками и resume.
В этих проверках ответы каталогов и API подменены фикстурами.

Отдельно на реальной ВМ получены и декодированы H.264/720p видео AnimeThemes
для MAL 37450 и 16498 (13,4 и 28,6 МБ; прогревочные файлы до изменения
ограничения 90 → 45 секунд). Проверен реальный структурированный ответ LRCLIB
для `the WORLD — NIGHTMARE`, включая записи TV/full с разной длительностью;
Lyrics.ovh тоже отвечает обычным текстом. Production build выполнен.
Новых ML-моделей и изменений нейросетевого inference в этом обновлении нет.
