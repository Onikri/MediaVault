# Серверные тексты песен

`POST /music/lyrics` требует обычную Bearer-сессию MediaVault. Тело:
`{titles: [...], artists: [...], duration: 153, rich: true, refresh: false}`.
Принимаются только метаданные песни: произвольные URL и параметры провайдера
не передаются. Ответ содержит phase, source, url, identity, lrc/lines/plainText,
timingMismatch, cached и elapsedMs. Секреты провайдера в ответ не входят.

Фазы: ready, empty, instrumental, restricted, error, busy. Сбой провайдера не
выдаётся за отсутствие текста. При отличающейся длительности допускается
только обычный текст; TV size, каверы, ремиксы и другие исполнители не смешиваются.

Musixmatch использует предоставленный пользователем мобильный token-flow.
Он не является официальным публичным Lyrics API и может перестать работать
независимо от MediaVault. Неактивный/вырожденный токен и известный ответ-заглушка
отбрасываются. Отказ доступа не обходится. Официальный API доступен при заданном
на ВМ MUSIXMATCH_API_KEY; наличие строковой/пословной разметки зависит от доступа.
Токен обновляется одним фоновым процессом до истечения, сохраняется в приватном
SQLite и никогда не создаётся внутри пользовательского поиска.

LRCLIB запускается параллельно с задержкой 300 мс. Оба адаптера ограничены общим
бюджетом 4 секунды, включая очередь; дополнительные запросы прекращаются при
готовом пословном результате. Завершённые задачи удаляются из ожидания.
Одинаковые запросы объединяются; уход одного клиента не отменяет остальных.

SQLite находится в server/.codex-local/lyrics при обычном запуске и в
/app/.codex-local/lyrics контейнера. Compose монтирует .codex-local/lyrics
из корня checkout ВМ. При создании mount каталог должен принадлежать uid 1000.
Кэш различает Unicode-названия, исполнителей, длительность и rich/plain запрос.
Пословные результаты хранятся сутки, остальные успешные — 5 минут, промахи —
10 минут, сбои — 10 секунд. Кэш ограничен 2000 записями; refresh явно обновляет его.
AMLL TTML DB остаётся клиентским улучшением строковых результатов до слов,
без задержки показа уже полученного текста. Без релея сохраняется прежний поиск.

Источники форматов и API:
- https://lrclib.net/docs
- https://www.postman.com/musixmatch-dev/musixmatch-apis/request/j136ay9/track-subtitle-get

Проверки: tests/test_music_lyrics.py — фикстуры провайдеров, реальные auth,
SQLite, deadline, очередь, отмена, объединение запросов, Unicode и richsync.
tests/lyric-search.test.mjs — контракт клиента и нормализация. Живые замеры
проводятся отдельно на Oracle; они не являются гарантией доступности каталога.
