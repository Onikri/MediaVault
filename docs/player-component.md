# MediaVaultPlayer

Один публичный React-компонент для онлайн-просмотра и файлов библиотеки.
`MediaViewer` и `OnlineViewer` подключают `MediaVaultPlayer` непосредственно.
`VideoPlayer.jsx` — совместимый реэкспорт этого же компонента для старых импортов.
Второго экземпляра плеера или параллельной реализации за ним нет.

## Владение состоянием

`player-controller.js` владеет ссылкой на основное видео, его состоянием,
настройками, прогрессом, субтитрами, дорожками, эффектами и переходами.
`MediaVaultPlayer.jsx` рисует интерфейс и предоставляет контекст расширениям.
Встроенные специализированные hooks продолжают выполнять потоковую загрузку,
синхронизацию звука, жесты и GPU-обработку.

`player-session.js` задаёт взаимоисключающие панели watch/settings/music/episodes,
стабильные команды, Media Session и освобождение расширений. Команды обращаются
к актуальному контроллеру через ссылку; смена React props не замыкает старые
source/item и не пересоздаёт API или медианоду.

Меню позиционируются абсолютно внутри плеера. Их координаты локальные, а
доступный размер учитывает контейнер и viewport при открытии/изменении размеров.
На маленьком плеере настройки и музыка разбиваются на меньшие страницы.
Кинотеатр затемняет соседние ветви DOM, а не предка с видео.

Основной video сам обрабатывает жесты и клик; над ним больше нет невидимого
полноэкранного слоя перехвата. Canvas апскейлера остаётся неинтерактивным.
Наличие браузерного PiP, fullscreen и поддержка кодеков определяются браузером.

## API расширений

```jsx
const marker = {
  id: 'episode-marker',
  slot: 'overlay', // либо footer
  setup({on, signal, getSnapshot}) {
    const stop = on('pause', () => {
      const current = getSnapshot();
      // Фоновые запросы модуля должны использовать signal.
    });
    return stop;
  },
  Component({player}) {
    return <button onClick={() => player.seek(30)}>К отметке</button>;
  }
};
<MediaVaultPlayer {...playbackProps} extensions={[marker]} apiRef={playerRef}/>
```

- У расширения уникальный стабильный `id`, стабильная функция `setup`.
- `setup` возвращает синхронную функцию очистки. Асинхронные операции запускаются
  внутри него с переданным AbortSignal. При удалении модуля сигнал отменяется,
  подписки `on` и возвращённая очистка автоматически освобождаются.
- Ошибка отрисовки расширения изолирована границей ошибок. Ошибка setup
  освобождает уже созданные ресурсы и передаётся через `onError`.
- Компонент расширения может также получить API через `useMediaVaultPlayer()`.
- Команды: `play`, `pause`, `toggle`, `seek(seconds)`, `preferences(patch)`,
  `openPanel(name)`, `fullscreen`, `pictureInPicture`, `theater(boolean)`,
  `selectItem(item, keepTime)`, `next`, `previous`.
- `getSnapshot()` возвращает актуальные item/source, время, длительность,
  состояние воспроизведения, настройки и режимы. `on` подписывает на нативные
  события основного media и возвращает функцию отписки.
- Расширение управляет общим плеером через команды и не создаёт свой video,
  HLS-клиент или дублирующее состояние воспроизведения.
- При отключении ограничений анимаций системное reduced motion сохраняется.

## Реестр переносимых функций

| Функция | Сохранённая реализация / проверки |
| --- | --- |
| Файлы библиотеки, онлайн-потоки, HLS, авто/ручное качество, буфер и восстановление | use-video-stream, use-playback-health; watch-page, player-comfort, browser |
| Независимая озвучка, аудиодорожки, громкость, mute, сдвиг звука | use-external-audio и контроллер; watch-page |
| HLS/native/external субтитры, загрузка SRT/VTT, размер и положение | контроллер и PlayerSettings; watch-page, player-model |
| Скорость, запоминание позиции и настроек, ссылка с таймкодом | playback-progress, use-player-actions; watch-page, player-session |
| Сезоны, эпизоды, варианты, автопереход, закрытие | player-model и контроллер; anime-navigation, browser |
| OP/ED, AniSkip, ручная разметка, сдвиг меток, автопропуск | use-episode-music и контроллер; watch-page, anime-navigation |
| Клавиатура, жесты перемотки/яркости/громкости/панелей | use-player-gestures и контроллер; design, player-session |
| Fullscreen, PiP, кинотеатр, автоматическое скрытие управления | контроллер и session; player-session, browser, design |
| Превью таймлайна и эпизодов | TimelinePreview, episode-preview-cache; watch-page |
| Anime4K, мобильный GPU, Lanczos, FSR, FSRCNN, цветокоррекция, статистика/повтор | существующие runtime-модули; fsr-browser, neural-upscaler, browser |
| Ambient, карта глубины и распознавание персонажей | use-player-atmosphere, PauseFrameEffects; pause-depth-browser |
| Музыка аниме и уведомление о текущей OP/ED | Soundtrack, use-episode-music; watch-page, music |
| Кадр, клип, ссылка, уведомления действий | use-player-actions; browser |
| Новые расширения, их удаление, общий API, нативный hit target | player-session-browser |

Реестр не означает проверку всех физических устройств и доступности каждого
внешнего источника. Проверки с подменёнными API отдельно от реального декодирования
медиа. Тест карты глубины использует контракт модели; при этой переработке новые
веса и реальный нейросетевой инференс отдельно не прогоняются. Алгоритмы моделей
и атрибуция не изменяются.

Этап 6 общего плана отдельно переносит навигацию между сезонами в устойчивую
оболочку страницы. Текущая миграция не обещает сохранить playback через размонтирование
самой страницы её родительским компонентом.
